# Official Project Name
FOvEA Intra (Optio vel Electio [aut] Arbitrium) is a project created by MattCraft_Dev.

# Game Concept
FI (FOvEA Intra) is an incremental, active idle game.
It revolves around the core concept of "carving your own path", and does the bare minimum in hand-holding.
There's no guide, no way you have to play, no thing to follow. You just play the way YOU want to.
You create your own personal way of playing the game.

## Actual Gameplay
You collect varying resources, from Knowledge to Matter to Soil.
The very interesting thing is you start with 3 top tabs (Creation, Invention & Settings dropdown) that spirals into a lot more things.

You have a total lifespan amount, that when reached, you die. There is no prestige, no bonus, nothing next run.
It MAY seem useless at first to try and play again, because you gain nothing..? Or do you? You now know how the game works.
And that connects back to the same core concept of not the game telling you what to do, but you figuiring it out yourself.
You don't see numbers go up faster next run because you gained a multiplier. No, they go up because you are better.
Because you know now what to do, what not to do, and how you have limited time to play.

You start collecting knowledge, then unlock training, which is just a fancy way to say 'Skills'. There is a varying amount of trainings to run through, spanning from Physical, Basic and Magic.
Leveling up those bars increases resources/unlocks other things, which contributes to getting more Inventions and unlocking more mechanics/tabs.

Which then fuel you to go farther even more.

## Official Goal
The major goal is to provide a fun, engaging, and entertaining game while learning JavaScript, HTML and CSS.
I started learning those languages a year ago (2025), with the help of AI, and now am transitioning to using with less and less AI.

### AI Stance
AI will be restricted, and only used for coding. When used, it will not be excessively used, or used to be lazy.
Only used when I, as the dev, hit an error/major code issue, that cannot be natively solved without external help.
After use, I will learn how to apply that to other coding practices, and will refrain in using AI unless I fall into that trap again.

### Requirements to run
It requires no software to use (Browser), and it is recommended to use Chrome or Edge to play.
